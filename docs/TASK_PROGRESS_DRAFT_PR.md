# Draft PR: Отображение этапов выполнения задач Developer Team

Карточки задач показывают назначение исполнителей, разработку, тестирование и исправления,
Reviewer и публикацию PR. Сохранены изменения Designer: тёмное оформление, адаптивная шкала,
переходы, доступные подписи и состав команды.

Worker сохраняет `currentStage` перед работой; API списка и отдельной задачи возвращает его.
Разработка охватывает всех исполнителей, исправления остаются на этапе тестирования.
Ошибки сохраняют этап остановки, повторная публикация атомарно возвращается в publication.
Для задач без PR публикация пропускается. Nullable-колонка добавляется при запуске без
выдумывания истории старых задач; UI поддерживает записи без этапа.
