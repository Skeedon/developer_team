# Draft PR: Аналитика работы ИИ-агентов

Добавлена адаптивная страница `/analytics.html` в тёмном стиле Developer Team: количество задач и исходы, средняя длительность, токены Developer/Reviewer, повторные исправления, график по датам UTC и последние 10 задач. Периоды: 7 дней, 30 дней, всё время.

Отдельный Minimal API `GET /api/analytics` выполняет агрегацию в PostgreSQL и ограничивает выборку отдельных задач десятью записями. Признаки наличия метрик отделяют исторические пропуски от измеренных нулей; при сбоях сохраняются доступные токены и число начатых исправлений. Ранее записанные положительные токены распознаются при обновлении схемы. Модели и compose.yaml не изменены, стоимость не рассчитывается, новых библиотек нет.

Добавлены unit-тесты суммирования по ролям, статусов, длительности, исправлений, UTC-периодов, пропущенных метрик, измеренных нулей и SQL-трансляции запросов Npgsql без подключения к БД.

Дополнительно прошли автономные проверки C#-логики агрегации, исторических null, границ периода и парсинга метрик, а также проверки рендеринга JavaScript: пустой период, отсутствие метрик, нулевые токены, экранирование пользовательского текста. Временный проверочный проект удалён.

Проверки: `node --check src/DeveloperTeam/wwwroot/analytics.js` и `git diff --check` пройдены. Полная сборка и xUnit заблокированы средой: MSBuild не может открыть системный сокет; однопоточный запуск обходит эту ошибку, но восстановление зависимостей завершается NU1301 (доступ к api.nuget.org:443 запрещён). Требуется повторить `dotnet test` в среде с доступными зависимостями и проверить endpoint на PostgreSQL.
