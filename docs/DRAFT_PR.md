# Draft: автоматические исправления после ошибок Test Runner

После первоначального запуска Developer Test Runner проверяет изменения. При ошибке Developer получает исходное задание, вывод тестов и текущий diff и исправляет тот же workspace. После каждой попытки тесты запускаются снова. `Worker:MaxFixAttempts` задаёт лимит исправлений: по умолчанию 2, значение 0 отключает исправления.

Независимый Reviewer запускается один раз после завершения цикла. Публикация Draft PR остаётся за пределами цикла. Исчерпание попыток сохраняет `TestStatus=failed`, видимый в интерфейсе, API и описании PR. История проверок содержит номер попытки, причину ошибки, описание исправлений и результат повторных тестов.

Исходный diff сохраняется отдельно в новой nullable-колонке `InitialDiff` до начала исправлений и доступен через `/api/tasks/{id}/initial-diff`. Существующие записи совместимы; `/diff` содержит итоговые изменения. Схема обновляется существующим механизмом `ADD COLUMN IF NOT EXISTS`.
