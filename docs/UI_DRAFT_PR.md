# Draft: современная панель управления Developer Team

Главная страница получила двухколоночную компоновку: создание задачи слева, сводка и карточки задач справа. На мобильных экранах блоки выстраиваются в одну колонку. Существующий тёмный стиль дополнен сдержанным сиреневым акцентом, единой типографикой, отступами и состояниями элементов.

## Изменения

- Выбор Developer / Designer через нативную радиогруппу с карточками и пояснениями.
- Пошаговая форма, подсказки полей, счётчик символов и выделенное основное действие.
- Карточки задач с исполнителем, текстовым статусом, репозиторием, веткой, датой, проверками, токенами и действиями.
- Сводка активных, завершённых и ошибочных задач; состояния загрузки, отсутствия задач и ошибки.
- Клавиатурный фокус, ссылка перехода к содержимому, семантические группы полей, поддержка reduced motion. Неизменившиеся данные не перерисовываются при опросе API.
- CSS и JavaScript вынесены в локальные файлы. Новых зависимостей нет.

Backend, API, бизнес-логика, модели и Docker не изменены. Сохранены создание задач, Draft PR checkbox, логи, diff, проверки, ZIP, ссылки PR, повтор публикации и память Reviewer.

## Проверки

- `node --check src/DeveloperTeam/wwwroot/dashboard.js` — успешно.
- `node tests/ui/dashboard.test.cjs` — 5 сценариев успешно: связи формы, карточка и экранирование HTML, пустые/активные/ошибочные состояния, выбор агента и payload создания, просмотр артефактов и памяти.
- `git diff --check` — успешно.
- `dotnet test DeveloperTeam.sln --nologo` — MSBuild не смог создать IPC-сокет: Permission denied. Повтор с `-m:1 --disable-build-servers` завершился ошибкой NU1301: среда запрещает доступ к api.nuget.org:443. .NET-тесты не выполнены.
- Браузерная визуальная проверка не выполнена: браузер и инструменты browser automation в среде отсутствуют. Клиентские проверки используют mock DOM / API и не заменяют просмотр в браузере.

## Визуальная проверка перед merge

- Открыть `/` при ширине 1440, 1024, 768, 390 и 320 px; проверить переносы, длинные задания и URL, отсутствие горизонтальной прокрутки.
- Пройти форму клавиатурой; переключить исполнителя стрелками, проверить подсказку и placeholder.
- Проверить создание задачи с включённым и выключенным Draft PR, пустой исходной веткой.
- Проверить завершённую, выполняющуюся и ошибочную задачи; открыть лог, diff, проверки, ZIP, PR, память Reviewer и повтор публикации.
- Проверить фокус при автообновлении, сетевую ошибку и восстановление, настройку reduced motion.

## Статус PR

Это локальное описание для Draft PR. GitHub PR не создан: публикация ветки и PR противоречит прямому запрету на push и публикацию в задании. Изменения оставлены в рабочем дереве; push и публикация не выполнялись.
